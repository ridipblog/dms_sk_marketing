## Key Points of Discussion in the Last Meeting with NE Infra

### 1. Dealer Management System

The following points were discussed regarding the proposed Dealer Management System:

1. **Dealer Profile Details**
   The dealer profile/details page should display the dealer’s outstanding amount, along with separate credit and debit balances for better financial visibility.

2. **Invoice and Order Management**
   A single invoice/order may include one or more products. Therefore, the system should support multiple product entries within a single invoice.

3. **GST in Invoice**
   GST rate and GST amount should be included in the invoice calculation and display.

4. **Product Master Details**
   GST and HSN/SAC code fields are required in the product master so that invoice generation can be handled properly as per taxation requirements.

5. **Penalty Calculation**
   Penalty calculation should be introduced in the system. As discussed, the penalty will be calculated at 15% per year after 21 days.

6. **MIS Dashboard and Reports**
   An MIS dashboard is required to display charts, financial amounts, dealer-wise data, and performance-related reports. The dashboard should include filters such as Dealer, Branch Manager, Area Sales Manager, and ASO-wise views. The dashboard data should also allow click-to-view details for deeper analysis.

7. **Official Hierarchy**
   The system should follow the below official hierarchy:

   **Branch Manager (BM) → Area Sales Manager (ASM) → Assistant Section Officer (ASO) → Dealers**

   The hierarchy should be considered while designing user roles, access control, dashboard filters, reporting, and dealer assignment.
